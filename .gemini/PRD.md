# Minesweeper Web Game PRD (v1.0)

## 1. 개요

Next.js(TypeScript), Supabase, TailwindCSS 기술 스택을 활용하여 웹 브라우저에서 즐길 수 있는 지뢰찾기 게임을 개발한다. 사용자는 다양한 난이도의 게임을 플레이하고, 자신의 기록을 저장하며, 다른 사용자들과의 랭킹을 확인할 수 있다. 비로그인 사용자도 게임 플레이가 가능하며, 게임 종료 후 간단한 로그인/회원가입을 통해 기록을 저장할 수 있는 심플한 UX를 제공하는 것을 목표로 한다.

- **Tech Stack:** Next.js (TypeScript), Supabase, TailwindCSS
- **Target:** 웹 기반 지뢰찾기 게임 플랫폼

---

## 2. 데이터 모델 (Supabase Tables)

### 유저 테이블

사용자 정보를 저장한다. 간단한 인증을 위해 username과 password만을 이용한 인증 시스템을 사용한다.

필드 : 유저 이름(PK), 패스워드, 생성 시간

### 게임 기록 테이블

사용자의 모든 게임 플레이 기록을 저장한다.

필드 : 유저 이름(FK), 난이도, 승리 여부, 클리어 타임, 점수, 보드 사이즈(for custom game), 지뢰 갯수(for custom game), 플레이 일시

## 3. 페이지 및 라우팅

| Path       | Page             | Description                                     |
| ---------- | ---------------- | ----------------------------------------------- |
| `/`        | 메인 게임 페이지 | 난이도 선택 및 지뢰찾기 게임 플레이             |
| `/ranking` | 랭킹 리더보드    | 난이도별 클리어 시간 및 점수 랭킹 표시          |

## 4. 기능 명세

### 4.1. 게임 플레이

- **난이도 선택:**
  - 초급: 9x9 격자, 지뢰 10개
  - 중급: 16x16 격자, 지뢰 40개
  - 고급: 30x16 격자, 지뢰 99개
  - (v1.1) 커스텀: 사용자가 가로, 세로, 지뢰 개수 직접 설정
- **첫 클릭 보장:**
  - 사용자가 처음 클릭한 칸과 그 주변 8칸에는 지뢰가 생성되지 않는다.
- **빈칸 연쇄 개방:**
  - 클릭한 칸이 빈칸(주변 지뢰 0개)일 경우, 인접한 모든 빈칸과 숫자 칸들이 연쇄적으로 열린다.
- **기본 조작 (마우스):**
  - **좌클릭:** 닫힌 칸 열기. 지뢰가 있으면 게임 오버.
  - **우클릭:** 닫힌 칸에 깃발 또는 물음표 표시 (순환 토글: 없음 -> 깃발 -> 물음표 -> 없음).
  - **더블클릭 (또는 휠클릭):** 이미 열린 숫자 칸에 사용. 해당 숫자만큼 주변에 깃발이 꽂혀있으면, 나머지 닫힌 칸들을 자동으로 연다.
- **기본 조작 (키보드):**
  - **방향키:** 보드 내에서 커서 이동.
  - **Space:** 현재 커서 위치의 칸 열기.
  - **'f' 또는 '1':** 깃발 토글.
  - **'q' 또는 '2':** 물음표 토글.
  - **Shift + Space:** 자동 열기 (마우스 더블클릭과 동일 기능).
- **게임 상태:**
  - **승리:** 지뢰가 없는 모든 칸을 열었을 때.
  - **패배:** 지뢰가 있는 칸을 열었을 때.
  - 남은 지뢰 개수와 경과 시간이 실시간으로 표시된다.

### 4.2. 점수 시스템

- **클리어 시간:** 게임 시작부터 승리까지 걸린 시간. 랭킹의 주요 기준.
- **독립 스코어:** 플레이 중 발생하는 모든 상호작용(칸 열기, 깃발 사용 등)에 가중치를 부여하여 계산된 점수. 랭킹의 보조 기준.

### 4.3. 사용자 인증 및 기록

- **회원가입/로그인:**
  - 게임 종료 후 결과 화면에서 ID/PW 입력 폼을 제공한다.
  - 입력된 ID가 존재하지 않으면, 해당 정보로 즉시 계정을 생성할지 묻고, 동의 시 가입과 로그인을 동시에 처리한다.
  - 별도의 회원가입 페이지 없이, 로그인 과정에 통합하여 UX를 단순화한다.
- **기록 저장:**
  - **로그인 사용자:** 게임 종료 시 `game_records` 테이블에 자동으로 기록이 저장된다.
  - **비로그인 사용자:** 게임 종료 후 로그인/회원가입에 성공하면, 직전 플레이 기록이 해당 유저의 계정으로 저장된다.

### 4.4. 랭킹 리더보드

- 난이도별(초급, 중급, 고급)로 랭킹을 필터링하여 볼 수 있다.
- 랭킹은 `clear_time_ms`를 기본 기준으로 오름차순 정렬한다. 시간이 같을 경우 `score`를 보조 기준으로 내림차순 정렬한다.
- 상위 100명의 랭킹(순위, 사용자명, 클리어 시간, 점수)을 표시한다.
- 로그인한 사용자의 경우, 자신의 최고 기록이 전체 플레이어 중 상위 몇 %에 해당하는지 표시해준다.

## 5. UI/UX 상세

### 5.1. 메인 게임 페이지

- **상단:** 게임 로고, 난이도 선택 버튼(초급/중급/고급), 랭킹/내 기록 페이지 이동 링크.
- **중앙:**
  - 게임 정보: 남은 지뢰 수, 타이머(초 단위).
  - 지뢰찾기 게임 보드.
- **게임 종료 시:**
  - 화면 중앙에 결과(Success/Game Over), 클리어 시간, 점수를 표시하는 모달(Modal) 창이 나타난다.
  - **로그인 상태:** "확인" 버튼과 "다시하기" 버튼 표시.
  - **비로그인 상태:** 기록 저장을 위한 간단한 로그인/회원가입 폼을 모달 내에 표시.

### 5.2. 랭킹 페이지

- 드롭다운 메뉴를 통해 난이도를 선택할 수 있다.
- 선택된 난이도에 해당하는 랭킹 목록을 테이블 형식으로 표시 (순위, 유저명, 시간, 점수, 기록일).
- 페이지 상단에 자신의 최고 기록 및 백분위 순위를 요약하여 보여준다. (로그인 시)

### 5.3. 내 기록 페이지

- 로그인한 사용자만 접근 가능.
- 자신의 모든 `game_records`를 최신순으로 테이블 목록으로 보여준다. (난이도, 승패 여부, 시간, 점수, 플레이 일시)
- 난이도별 승률, 평균 클리어 시간 등 간단한 통계 정보를 시각화하여 제공한다.
